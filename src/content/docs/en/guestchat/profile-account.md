**Menu location:** `Settings → Profile`

This page shows the profile card of the currently logged-in staff member: photo, full name, username, email, and phone number, along with two main actions.

## Edit Profile

Staff can change their **profile photo** (click directly on the photo to upload a new image) and update their **First Name** and **Last Name**.

:::caution[Image not yet available]
Add a screenshot of the Edit Profile form. Example: `![Edit Profile](../../../../assets/guestchat/settings-edit-profile.png)`.

## Change Password

To change the password, staff need to fill in **Old Password**, then a **New Password** that must meet all of the following requirements (marked with a real-time green/red checklist):

- At least 6 characters
- Contains a lowercase letter
- Contains an uppercase letter
- Contains a number
- Contains a special character (e.g. `!@#$%^&*`)

The new password must also be re-typed in the **Confirm New Password** field and must match exactly.

:::caution[Image not yet available]
Add a screenshot of the Change Password form with the requirement checklist. Example: `![Change Password](../../../../assets/guestchat/settings-change-password.png)`.
:::

:::note[Note]
An incorrect old password will show a specific error message ("Incorrect current password") without revealing any other reason.
:::
