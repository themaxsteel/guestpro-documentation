When opening a conversation, the right panel (sidebar) displays complete guest information through several tabs, plus a message search feature and old chat import.

## Guest Profile Tab

Shows guest data: name, phone number (WhatsApp only), email, gender, and additional details (date of birth, address, nationality, ID number) that can be revealed via **Show More**.

:::caution[Image not yet available]
Add a screenshot of the Guest Profile tab in normal condition. Example: `![Guest Profile Tab](../../../../assets/guestchat/room-sidebar-guest-profile.png)`.
:::

If guest data is stored in encrypted (masked) form, e.g.: `08******123`, staff need to click the eye icon to **unmask** it — some conditions require OTP verification first before the real data is shown.

:::caution[Image not yet available]
Add a screenshot of masked data along with the unmask icon. Example: `![Guest Profile Data Masked](../../../../assets/guestchat/room-sidebar-guest-profile-masked.png)`.
:::

Also available at the bottom of this tab:
- **Guest Segments** — the guest's active segmentation.
- **Chat Notes (Staff Only)** — internal notes visible only to staff, not the guest.

## Memories Tab

A photo gallery of moments/memories with the guest (for example, photos taken at check-in or a special event). Staff can add new photos, resend a photo to the chat, or delete it.

:::caution[Image not yet available]
Add a screenshot of the Memories tab with a photo gallery. Example: `![Memories Tab](../../../../assets/guestchat/room-sidebar-memories.png)`.
:::

## Reservation Tab

Shows the guest's current stay information: invoice & folio number, check-in/check-out dates, number of nights, room type, number of guests (adults/children), booking ID, remarks, and special requests. Remarks and special requests can be edited directly from here by staff.

:::caution[Image not yet available]
Add a screenshot of the Reservation tab, including remark/special request edit mode. Example: `![Reservation Tab](../../../../assets/guestchat/room-sidebar-reservation.png)`.
:::

## History Tab

Shows the guest's complete history at the property: total lifetime spend (**Lifetime Spend**), their most frequently/heavily purchased products, and a combined timeline of stay history (**Stay**) and POS transactions (**Order**) that can be filtered by type.

:::caution[Image not yet available]

:::

## Search Messages Within a Chat (Search Message)

A search feature for finding old messages within a conversation without manual scrolling — matching keywords are highlighted in the search results.

## Import Old WhatsApp Chat

To move WhatsApp chat history that occurred before the guest was connected to GuestChat, staff can upload a **`.txt`** file exported from WhatsApp, then map which names are Staff/Admin and which are Guest before running the import.

:::caution[Image not yet available]
Add a screenshot of the Import Chat modal (before & after the file is uploaded with name mapping). Example: `![Import Chat Modal](../../../../assets/guestchat/room-import-chat-modal.png)`.
:::

:::tip[How to Export Chat from WhatsApp]
In the WhatsApp app: open the chat you want to export → three-dot menu → **More** → **Export Chat** → choose **Without Media** so the result is a `.txt` file.
:::
